Frequency complements (doing something ... times)

HSK 3

動詞 + 了／过 + 回数（次・遍・趟・下）+ 目的語

The number of times an action is done goes after the verb. 「次」 is for times in general, 「遍」 for once through from start to finish (「看了三遍」), 「趟」 for one round trip (「去了一趟」), and 「下」 for brief actions (「敲了两下门」). As a rule, a personal pronoun object goes before the number of times (「见过他两次」), and an ordinary noun object after it (「去过两次北京」).

×「我两次去过北京。」→ The number of times goes after the verb. Another key point is that a pronoun object goes before it: 「见过他一次」.

Example sentences

我去过两次北京。
wǒ qù guo liǎng cì běi jīng。
I've been to Beijing twice.
