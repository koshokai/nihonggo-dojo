「除了…以外」: except ..., besides ...

HSK 3

除了 + A +（以外），（主語）+ 都 … ／ 还・也 …

If 「都」 follows, it means exclusion: "except A, (all) ...." If 「还」 or 「也」 follows, it means addition: "besides A, also ...." 「以外」 can be omitted. The key point is that 「都」 versus 「还」/「也」 in the second half gives opposite meanings.

「除了A，都…」 = A is not included; 「除了A，还…」 = A is included too. Always check the adverb in the second half before translating.

Example sentences

除了小王以外，大家都来了。
chú le xiǎo wáng yǐ wài， dà jiā dōu lái le。
Everyone came except Xiao Wang.
