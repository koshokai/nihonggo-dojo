「只有…才…」: only if ..., only by ...

HSK 4

只有 + 唯一の条件，（主語）+ 才 + 結果

Emphasizes the only condition (a necessary condition): "without this condition, the result won't happen." 「只有多练习，才能说好」 means "Only by practicing a lot can you speak well (otherwise you can't)." It sounds stricter than 「只要」. The second half always pairs with 「才」, never 「就」.

×「只有努力，就能成功。」→ 「只有」 goes with 「才」. Be careful not to swap the pairings with 「只要…就」.

Example sentences

只有努力学习，才能通过考试。
zhǐ yǒu nǔ lì xué xí， cái néng tōng guò kǎo shì。
Only by studying hard can you pass the exam.
