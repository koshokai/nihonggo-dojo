「除非…否则／才…」: unless ..., only if ...

HSK 5

除非 + 唯一の条件，否则／不然 + 結果 ／ 除非 + 条件，才 + 結果

「除非」 presents the one and only condition: "unless ... / only if ..." 「除非A，否则B」 means "unless A, B will happen," and 「除非A，才B」 means "only if A will B happen." Note that the condition after 「除非」 is written in the affirmative, just as after English "unless" (not "unless it doesn't ...").

×「除非不下雨」 → To say "unless it rains," think of it in the structure 「除非下雨，否则…」 ("unless it rains; if it doesn't, ..."), with no negative after 「除非」. It's close in meaning to 「只有…才…」.

Example sentences

除非下大雨，否则比赛照常进行。
chú fēi xià dà yǔ， fǒu zé bǐ sài zhào cháng jìn xíng。
Unless it rains heavily, the match will go ahead as usual.
