「万一」: in case, if by any chance

HSK 5

万一 + 起こり得る悪い事態，（就）+ 対策 ／ 以防万一

「万一」 is a conjunction that supposes an unwanted situation: "it's unlikely, but if by any chance ..." It is close to English "in case" or "if by some chance," and is followed by a countermeasure or worry. Unlike 「如果」, it's characteristically used only for bad situations. As a noun, it also appears in the set phrase 「以防万一」 ("just in case").

「万一」 isn't used to suppose good things (×「万一中奖了」). For good things, use 「如果・要是」.

Example sentences

万一下雨，我们就改天再去。
wàn yī xià yǔ， wǒ men jiù gǎi tiān zài qù。
If by any chance it rains, we'll go another day.
