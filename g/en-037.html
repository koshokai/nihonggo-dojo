should have done / needn't have done

本应该……（却没有）；本不必……（却做了） · 四级

should have done 表示过去该做而没做，带有责备或后悔；shouldn't have done 表示不该做却做了；needn't have done 表示本不必做却做了。

例句

You should have told me earlier.
你本该早点告诉我的。
I shouldn't have eaten so much.
我不该吃那么多的。
You needn't have brought a gift, but thank you!
你其实不用带礼物的，不过谢谢你！
