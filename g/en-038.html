虚拟语气 if I were …（与现在事实相反）

要是……就好了 / 如果……就会…… · 四级

If + 主语 + 过去式（be 一律用 were），主句用 would / could / might + 动词原形，表示与现在事实相反或不太可能实现的假设。

例句

If I were you, I would accept the offer.
如果我是你，我会接受这份工作。
If I had more time, I could travel around the world.
如果我有更多时间，我就能环游世界了。
What would you do if you won the lottery?
如果你中了彩票，你会做什么？
