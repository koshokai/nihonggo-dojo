虚拟语气 if I had done（与过去事实相反）

要是当时……就会……了 · 四级

If + 主语 + had + 过去分词，主句用 would / could / might + have + 过去分词，表示与过去事实相反的假设，常带遗憾语气。

例句

If I had left earlier, I wouldn't have missed the flight.
要是我早点出发，就不会误机了。
If she had asked for help, we would have helped her.
她当时要是开口求助，我们肯定会帮她。
We could have won if we had played better.
要是我们发挥得好一些，本来是能赢的。
