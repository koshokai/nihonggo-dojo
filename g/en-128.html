目的状语 in order to / so as to / so that

为了…… · 四级

in order to / so as to + 动词原形表示目的，否定为 in order not to / so as not to（so as to 不放句首）；主语不同或要用情态动词时用 so that / in order that + 从句（常含 can / could / will / would）。

例句

She got up early in order to catch the first bus.
她早起是为了赶上头班车。
Speak quietly so as not to wake the baby.
小声说话，以免吵醒宝宝。
I'll explain it again so that everyone can understand.
我再解释一遍，好让大家都能听懂。
