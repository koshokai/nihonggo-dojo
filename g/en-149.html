伪分裂句 All (that) … is / The only thing … is (to) do

……所做的 / 所需要的只是…… · 六级

All (that) / The only thing / The last thing + 从句 + be + 表语，用于强调；从句中含 do 时，表语可用不带 to 的不定式（All you have to do is press the button）。注意 All 在这里相当于 the only thing，谓语用单数。

例句

All I want is a quiet weekend.
我只想过个安静的周末。
All you need to do is fill in this form.
你只需要填好这张表。
The last thing I expected was an apology from him.
我最没想到的就是他会道歉。
