if only + 虚拟

要是……就好了 · 六级

if only 表达强烈的愿望或遗憾，比 I wish 语气更强：与现在事实相反用过去式（were），与过去事实相反用 had done，对将来的愿望用 would / could do。

例句

If only I were taller!
要是我再高一点就好了！
If only I had listened to your advice.
要是我当初听了你的建议就好了。
If only the rain would stop!
雨要是能停就好了！
