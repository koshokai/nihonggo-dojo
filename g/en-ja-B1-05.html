第一条件文（実際に起こりうる条件）

CEFR B1

If ＋ 現在形, will ＋ 動詞の原形

将来に実際に起こりうる条件と、その結果を表します。if 節は未来のことでも現在形を使い、主節には will、can、may や命令文を使います。if 節が前に来るときはコンマを入れ、後ろに来るときは入れません。

「明日雨が降ったら」は未来のことなので If it will rain tomorrow としがちですが、if 節は現在形で If it rains tomorrow とします。when や as soon as の節も同じです。

例文

If it rains tomorrow, we will stay home.
明日雨が降ったら、家にいます。
If you hurry, you can catch the last bus.
急げば最終バスに間に合いますよ。
I'll call you if I hear any news.
何か知らせがあったら電話しますね。
If you see Tom, please tell him about the party.
トムに会ったら、パーティーのことを伝えてください。
