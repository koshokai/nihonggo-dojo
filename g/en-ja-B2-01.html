仮定法過去完了（第三条件文）

CEFR B2

If ＋ had ＋ 過去分詞, would / could / might have ＋ 過去分詞

過去に実際には起こらなかったことを想像して「もしあの時〜だったら、〜しただろう」と言う形で、後悔や安堵の気持ちを表します。if 節は過去完了（had done）、主節は would have done を使います。could have / might have は「〜できただろう／〜したかもしれない」。今さら変えられない過去の話である点が、仮定法過去（第二条件文）との違いです。

日本語の「もし〜だったら」は時制が変わらないため、過去の話でも If I knew と言いがちです。過去の仮定は If I had known, I would have come。if 節に would have を入れるのも誤りです。

例文

If we had left earlier, we wouldn't have missed the train.
もっと早く出ていれば、電車に乗り遅れなかったのに。
She would have called you if she had known your number.
あなたの番号を知っていたら、彼女は電話していたでしょう。
If I hadn't taken that class, I might never have met my wife.
あの授業を取っていなかったら、妻に出会うことはなかったかもしれません。
What would you have done if the store had been closed?
もし店が閉まっていたら、どうしていましたか。
