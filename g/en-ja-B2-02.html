混合型の仮定法

CEFR B2

If ＋ had ＋ 過去分詞, would ＋ 原形（過去→現在）／ If ＋ 過去形, would have ＋ 過去分詞（現在→過去）

混合型は、条件と結果で時間がずれている文です。よくあるのは「過去の条件 → 現在の結果」：If I had saved money, I would be rich now. もう一つは「今も続いている状態 → 過去の結果」：If I weren't so shy, I would have talked to her. 前半と後半がそれぞれいつの話かを見て、形を選びましょう。

「あの時〜していたら、今ごろ〜」の「今」の部分まで would have にしてしまう間違いが多いです。now や still があれば、主節は would ＋原形です。

例文

If I had saved more money, I wouldn't be so worried now.
もっと貯金していたら、今こんなに心配していないでしょう。
If she hadn't moved abroad, she would still be working here.
海外に引っ越していなければ、彼女は今もここで働いているでしょう。
If he were more careful, he wouldn't have lost his keys again.
彼がもっと注意深ければ、また鍵をなくすことはなかったでしょう。
If I didn't speak English, I wouldn't have gotten this job.
英語が話せなかったら、この仕事には就けなかったでしょう。
