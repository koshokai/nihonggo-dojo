were to / if it were not for（仮定と「〜がなければ」）

CEFR C1

If ＋ 主語 ＋ were to ＋ 動詞の原形, 主語 ＋ would…；If it were not for ＋ 名詞（現在）／ If it had not been for ＋ 名詞（過去）

If … were to do は「仮に〜するとしたら」という未来の仮定で、if ＋ 過去形よりも「あくまで仮の話」という感じが強く、可能性の低いことや言いにくいことを婉曲に言うときに使います。If it were not for ＋ 名詞 は「〜がなければ」で現在の話、過去なら If it had not been for ＋ 名詞 を使います。フォーマルな文では Were it not for / Had it not been for と倒置できます。

日本語の「〜がなかったら」は現在と過去の区別があいまいです。過去の話では If it had not been for を使い、主節も would have done にします。

例文

If you were to move abroad, which country would you choose?
仮に海外に移住するとしたら、どの国を選びますか。
If it were not for coffee, I couldn't get through Mondays.
コーヒーがなかったら、月曜日を乗り切れないでしょう。
If it had not been for your advice, I would have quit.
あなたの助言がなかったら、私は辞めていたでしょう。
Were it not for the rain, we could eat outside.
雨さえ降っていなければ、外で食事できるのに。
