丁寧な依頼：I was wondering if / I'd appreciate it if

CEFR C1

I was wondering if / whether ＋ 主語 ＋ could…；I'd appreciate it if ＋ 主語 ＋ could…；Would it be possible to…?

英語では過去形・過去進行形や would を使って依頼に「距離」を置き、相手に負担をかけない丁寧な響きにします。I was wondering if you could… は過去進行形ですが、今のお願いを表します。I'd appreciate it if you could… はメールでよく使い、appreciate の後の it は省けません。I was hoping you might… や Would it be possible to…? も同じ働きです。

日本語の丁寧さは語尾で表しますが、英語では過去形や would で距離を置きます。I'd appreciate it if の it を落とす間違いに注意しましょう。

例文

I was wondering if you could look over my resume.
履歴書に目を通していただけないかと思いまして。
I'd appreciate it if you could reply by Thursday.
木曜日までにご返信いただけると幸いです。
I was hoping we could move the call to Friday.
通話を金曜日に変更できればと思っていたのですが。
Would it be possible to get a copy of the slides?
スライドのコピーをいただくことは可能でしょうか。
