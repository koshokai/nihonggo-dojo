比較の慣用表現：not so much A as B / all the more

CEFR C1

not so much A as B（AというよりB）；all the ＋ 比較級 ＋ because / since / for…；none the ＋ 比較級

not so much A as B は「AというよりむしろB」で、A と B は同じ品詞にそろえます。all the ＋ 比較級 は「（ある理由で）なおさら〜」で、後ろに because / since / for ＋ 名詞 が続くことが多いです。逆の none the ＋ 比較級 は「それでも少しも〜ない」で、I read the manual but was none the wiser（説明書を読んでもさっぱりわからなかった）のように使います。

語順は日本語の「AというよりB」と同じで、本当に言いたいのは後ろの B です。as を than にしたり、all the more の the を落としたりする誤りに注意しましょう。

例文

She is not so much shy as careful with words.
彼女は内気というより、言葉を慎重に選ぶ人です。
The problem is not so much the cost as the time.
問題は費用というより時間です。
The view was all the more beautiful after the long climb.
長い登りの後だったので、景色はいっそう美しく感じられました。
His apology meant all the more because he rarely apologizes.
彼はめったに謝らないので、その謝罪はなおさら重みがありました。
