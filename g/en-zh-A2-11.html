should / shouldn't（建议）

CEFR A2

should / shouldn't + 动词原形

should 用来给建议或表示“应该”，语气比 must 温和。shouldn't 表示“不应该、最好别”。征求意见时说 Should I …? 或 What should I do? 常和 I think 连用，让建议听起来更委婉：I think you should rest.

should 后面直接跟动词原形，不加 to：✗ You should to see a doctor. “我觉得你不应该……”英语通常说 I don't think you should …，把否定放在 think 上。

例句

You should see a doctor about that cough.
你咳成这样，应该去看看医生。
You shouldn't drink coffee so late at night.
你不应该这么晚还喝咖啡。
What should I wear to the interview?
面试我应该穿什么？
I think we should leave now. It's getting dark.
我觉得我们该走了，天快黑了。
