第一条件句（可能发生的条件）

CEFR B1

If + 一般现在时, will + 动词原形

用来说将来很可能发生的情况，以及它带来的结果。if 从句虽然说的是将来，但要用一般现在时；主句用 will、can、may 或祈使句。if 从句放在前面时后面加逗号，放在后面时不加。

中文“如果明天下雨”没有时态标记，很多人想到“将来”就写成 If it will rain tomorrow，正确的是 If it rains tomorrow。when、as soon as、before 引导的时间从句也一样用现在时。

例句

If it rains tomorrow, we will stay home.
如果明天下雨，我们就待在家里。
If you hurry, you can catch the last bus.
你快一点的话，就能赶上末班车。
I'll call you if I hear any news.
如果有什么消息，我就给你打电话。
If you see Tom, please tell him about the party.
如果你见到汤姆，请告诉他聚会的事。
