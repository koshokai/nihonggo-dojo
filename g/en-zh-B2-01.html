第三条件句：与过去事实相反的假设

CEFR B2

If + had + 过去分词, would / could / might have + 过去分词

用来想象过去没有发生的事：“如果当时……，就会……”，常带有后悔或庆幸的语气。if 从句用过去完成时（had done），主句用 would have done；could have / might have 表示“本来能够 / 可能会”。和第二条件句不同，它说的是已经无法改变的过去。

中文“要是当时……就……”没有时态变化，所以常有人说成 If I knew, I would come。讲过去要用 If I had known, I would have come；也不要在 if 从句里用 would have（×If I would have known）。

例句

If we had left earlier, we wouldn't have missed the train.
要是我们早点出发，就不会错过火车了。
She would have called you if she had known your number.
她要是知道你的号码，早就给你打电话了。
If I hadn't taken that class, I might never have met my wife.
要是没上那门课，我可能永远不会遇见我妻子。
What would you have done if the store had been closed?
要是那家店关门了，你会怎么办？
