混合条件句

CEFR B2

If + had + 过去分词, would + 动词原形（过去→现在）；If + 过去式, would have + 过去分词（现在→过去）

混合条件句把两个时间放在一句里。最常见的是“过去的条件 → 现在的结果”：If I had saved money, I would be rich now. 另一种是“现在一直存在的情况 → 过去的结果”：If I weren't so shy, I would have talked to her. 关键是分别看两半各说哪个时间，再选形式。

很多人把所有假设都套成第三条件句，结果“现在”那一半也写成 would have。句子里有 now、today、still 时，主句通常用 would + 动词原形。

例句

If I had saved more money, I wouldn't be so worried now.
如果当初多存点钱，我现在就不会这么担心了。
If she hadn't moved abroad, she would still be working here.
如果她没出国，现在应该还在这里工作。
If he were more careful, he wouldn't have lost his keys again.
他要是细心一点，就不会又把钥匙弄丢了。
If I didn't speak English, I wouldn't have gotten this job.
要是我不会说英语，就不会得到这份工作。
