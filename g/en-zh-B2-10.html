介词 + 关系代词

CEFR B2

名词 + 介词 + which / whom + 从句（正式）；名词 + (that / who) + 从句 + 介词（口语）

定语从句里的动词需要介词时（talk to、live in、depend on），介词可以放在 which / whom 前面（较正式），也可以留在从句末尾（口语更常见）：the person to whom I spoke = the person (who) I spoke to。介词放在前面时，只能用 which 或 whom，不能用 that 或 who。

两个常见错误：一是介词重复（×the house in which I live in），二是介词放在前面却用 that 或 who（×the topic about that we talked）。

例句

This is the town in which I grew up.
这就是我长大的小镇。
The people with whom I work are very friendly.
和我一起工作的人都很友好。
That's the song I was telling you about.
那就是我跟你说过的那首歌。
The project on which we spent months was finally approved.
我们花了好几个月做的那个项目终于获批了。
