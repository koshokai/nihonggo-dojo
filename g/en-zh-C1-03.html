were to / if it were not for（假设与“要不是”）

CEFR C1

If + 主语 + were to + 动词原形, 主语 + would…；If it were not for + 名词（现在）/ If it had not been for + 名词（过去）

If … were to do 表示对未来的假设，比 if + 过去式更强调“只是假设”，常用来谈不太可能或比较敏感的情况，语气也更委婉。If it were not for + 名词 表示“要不是有……”，谈现在的情况；谈过去要用 If it had not been for + 名词。正式文体中可以倒装成 Were it not for / Had it not been for。

中文“要不是……”不分现在和过去，学习者常混用。谈过去的事要用 If it hadn't been for your help, I would have failed，主句也要用 would have done。

例句

If you were to move abroad, which country would you choose?
假如你要移居国外，你会选哪个国家？
If it were not for coffee, I couldn't get through Mondays.
要不是有咖啡，我根本熬不过星期一。
If it had not been for your advice, I would have quit.
要不是你的建议，我早就放弃了。
Were it not for the rain, we could eat outside.
要不是下雨，我们就可以在外面吃饭了。
