委婉请求：I was wondering if / I'd appreciate it if

CEFR C1

I was wondering if / whether + 主语 + could…；I'd appreciate it if + 主语 + could…；Would it be possible to…?

英语常用过去时、过去进行时或 would 和请求“拉开距离”，听起来更客气，不给对方压力。I was wondering if you could… 虽然是过去进行时，说的却是现在的请求。I'd appreciate it if you could… 常用于邮件，appreciate 后面的 it 不能省。类似的还有 I was hoping you might… 和 Would it be possible to…?

常见错误是漏掉 it：×I'd appreciate if you could…。也有人以为 I was wondering 是在说过去，改成 I wonder if…，反而显得更直接。

例句

I was wondering if you could look over my resume.
不知道您能不能帮我看看简历。
I'd appreciate it if you could reply by Thursday.
如果您能在周四前回复，我将不胜感激。
I was hoping we could move the call to Friday.
我想问问能不能把电话会议改到周五。
Would it be possible to get a copy of the slides?
能不能给我一份幻灯片？
