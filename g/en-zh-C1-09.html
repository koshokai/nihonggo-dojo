比较惯用语：not so much A as B / all the more

CEFR C1

not so much A as B（与其说是A，不如说是B）；all the + 比较级 + because / since / for…；none the + 比较级

not so much A as B 表示“与其说是 A，不如说是 B”，A 和 B 的词性要一致。all the + 比较级 表示“（因为某个原因）反而更加……”，后面常接 because / since / for + 名词。相反的说法 none the + 比较级 表示“并没有因此更……”，如 I read the manual but was none the wiser（看了说明书还是不明白）。

as 常被误写成 than 或 but：×not so much angry than sad。all the more 中的 the 也常被漏掉。

例句

She is not so much shy as careful with words.
与其说她害羞，不如说她说话谨慎。
The problem is not so much the cost as the time.
问题与其说是费用，不如说是时间。
The view was all the more beautiful after the long climb.
经过漫长的攀登，风景显得更加美丽。
His apology meant all the more because he rarely apologizes.
他很少道歉，所以这次道歉更显珍贵。
