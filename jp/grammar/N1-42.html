～ならいざしらず

it might be understandable if ..., but · JLPT N1

How to use it: Noun / plain form + ならいざしらず. The first part is a special, understandable case; the second part points out that the current situation is unacceptable. Note: although it contains 知らず, it does not mean "not know" here.
