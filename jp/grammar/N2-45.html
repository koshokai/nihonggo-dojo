～はともかく

setting aside, leaving ... aside · JLPT N2

How to use it: Noun + はともかく (として). Puts the first item aside for now and gives priority to the second. Note that this is the opposite of 「はもちろん」: the first item is temporarily set aside rather than taken for granted.
