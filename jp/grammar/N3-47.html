～まま

as is, remaining in the same state · JLPT N3

How to use it: Verb た-form / ない-form, い-adjective, な-adjective + な, noun + の + まま. Means doing the second action while a certain state stays unchanged; a common mistake is attaching it to the verb dictionary form.
