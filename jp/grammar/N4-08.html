～ば

if ..., (then) · JLPT N4

How to use it: Verb conditional form (e-row sound) + ば; い-adjective minus い + ければ.

Example sentences

この薬くすりを飲のめば、すぐ治なおりますよ。
If you take this medicine, you'll get better right away.
安やすければ、買かいます。
If it's cheap, I'll buy it.
急いそげば、間まに合あいます。
If you hurry, you'll make it in time.
練習れんしゅうすれば、上手じょうずになります。
If you practice, you'll get better.
