～ので

because, so (objective reason) · JLPT N4

How to use it: Plain form + ので (な-adjective / noun + なので).

Example sentences

雨あめが降ふっているので、出でかけません。
It's raining, so I'm not going out.
頭あたまが痛いたいので、早はやく帰かえります。
I have a headache, so I'm going home early.
明日あしたは休やすみなので、ゆっくり寝ねます。
Tomorrow is a day off, so I'll sleep in.
道みちが込こんでいたので、遅おくれました。
The roads were crowded, so I was late.
