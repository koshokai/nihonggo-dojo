～てある

(something) has been done (on purpose) and remains that way · JLPT N4

How to use it: Transitive verb て-form + ある, often in the pattern 「～が～てある」, shows that the result of an action someone did on purpose still remains. Note: intransitive verbs cannot take てある (wrong: ドアが開いてある; right: ドアが開いている / ドアが開けてある).

Example sentences

窓まどが開あけてあります。
The window has been left open.
壁かべに地図ちずが貼はってあります。
A map has been put up on the wall.
ビールはもう冷蔵れいぞう庫こに入いれてあります。
The beer has already been put in the fridge.
ホテルはもう予約よやくしてあります。
The hotel has already been booked.
