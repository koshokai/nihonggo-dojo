～出す

suddenly start to · JLPT N4

How to use it: Verb ます-stem + 出す. Expresses that an action starts suddenly, mostly for things beyond one's control (crying, laughing, rain, running, etc.). It cannot be used for planned actions (wrong: 明日から勉強し出します; right: 勉強し始めます).

Example sentences

赤あかちゃんが急きゅうに泣なき出だしました。
The baby suddenly started crying.
話はなしを聞きいて、みんな笑わらい出だしました。
Hearing the story, everyone burst out laughing.
急きゅうに雨あめが降ふり出だしました。
It suddenly started to rain.
犬いぬが突然とつぜん走はしり出だしました。
The dog suddenly started running.
