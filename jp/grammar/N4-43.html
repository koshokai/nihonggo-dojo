～までに

by (a deadline) · JLPT N4

How to use it: Noun / verb dictionary form + までに. Shows the deadline by which a one-time action is completed. Difference from 「まで」: まで means an action continues up until a certain time (wrong: 5時までに待つ; right: 5時まで待つ).

Example sentences

金曜きんよう日びまでにレポートを出だしてください。
Please submit the report by Friday.
9く時じまでに会社かいしゃに来きてください。
Please come to the office by 9.
暗くらくなるまでに家いえに帰かえりましょう。
Let's go home before it gets dark.
来週らいしゅうまでにこの本ほんを返かえします。
I'll return this book by next week.
