～て／～くて (reason)

because ..., (so) · JLPT N4

How to use it: Verb て-form; い-adjective minus い + くて; な-adjective / noun + で. Expresses a cause; the second part is usually a feeling, state, or ability (うれしい, 困る, できない, etc.). It cannot be followed by an expression of intention, a command, or a request (wrong: 暑くて窓を開けてください; right: 暑いから窓を開けてください).

Example sentences

ニュースを聞きいて、びっくりしました。
I was surprised to hear the news.
この問題もんだいは難むずかしくて、わかりません。
This problem is so difficult that I can't do it.
かばんが重おもくて、持もてません。
The bag is so heavy that I can't carry it.
久ひさしぶりに友達ともだちに会あえて、うれしかったです。
I was happy to see my friend for the first time in a long time.
