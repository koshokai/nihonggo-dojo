～てもかまわない

it's all right if, I don't mind if · JLPT N4

How to use it: Verb て-form / い-adjective くて / な-adjective or noun + で + もかまわない. Same meaning as 「～てもいい」 but slightly more formal; the negative 「～なくてもかまわない」 means there is no need to.

Example sentences

ここで写真しゃしんを撮とってもかまいません。
It's all right to take pictures here.
明日あしたは来こなくてもかまいません。
It's all right if you don't come tomorrow.
少すこし高たかくてもかまいません。
I don't mind if it's a little expensive.
ボールペンで書かいてもかまいませんか。
Is it all right if I write with a ballpoint pen?
