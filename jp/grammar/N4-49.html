～なら

if (giving advice on a topic the listener raised) · JLPT N4

How to use it: Verb / い-adjective plain form, noun / な-adjective stem + なら. Picks up a topic the other person mentioned and gives advice or a judgment. Unlike 「たら」, with なら the second part can happen before the first (「行くなら地図を買っておこう」).

Example sentences

日本にほんへ行いくなら、夏なつより秋あきがいいですよ。
If you're going to Japan, autumn is better than summer.
パソコンを買かうなら、この店みせが安やすいです。
If you're going to buy a computer, this shop is cheap.
すしなら、駅前えきまえの店みせがおいしいです。
If it's sushi you want, the place in front of the station is good.
疲つかれているなら、早はやく休やすんだほうがいいです。
If you're tired, you should get some rest early.
