～場合は

in case of, if · JLPT N4

How to use it: Verb plain form / い-adjective / な-adjective + な / noun + の + 場合は. Explains what to do in a certain situation; more formal than 「たら」 and common in notices, instructions, and rules.

Example sentences

雨あめの場合ばあいは、試合しあいは中止ちゅうしです。
In case of rain, the game will be canceled.
遅おくれる場合ばあいは、電話でんわで連絡れんらくしてください。
If you're going to be late, please let us know by phone.
火事かじの場合ばあいは、エレベーターを使つかわないでください。
In case of fire, do not use the elevator.
わからない場合ばあいは、係かかりの人ひとに聞きいてください。
If anything is unclear, please ask a staff member.
