～ませんか

won't you ...? / would you like to ...? (invitation) · JLPT N5

How to use it: Verb ます-stem + ませんか.

Example sentences

一緒いっしょに昼ひるご飯はんを食たべませんか。
Would you like to have lunch together?
週末しゅうまつ、映画えいがを見みませんか。
Would you like to see a movie this weekend?
少すこし休やすみませんか。
Would you like to take a little break?
コーヒーを飲のみませんか。
Would you like some coffee?
