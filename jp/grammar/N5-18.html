～てください

please do · JLPT N5

How to use it: Verb て-form + ください.

Example sentences

ここに名前なまえを書かいてください。
Please write your name here.
ちょっと待まってください。
Please wait a moment.
窓まどを開あけてください。
Please open the window.
もう一いち度ど言いってください。
Please say it one more time.
