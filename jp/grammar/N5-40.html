～があります／～がいます

there is / there are; to be (located) · JLPT N5

How to use it: Place + に + noun + が + あります (inanimate things, plants) / います (people, animals). English uses "there is / there are" for both, but Japanese must distinguish between living and non-living things.

Example sentences

机つくえの上うえに本ほんがあります。
There is a book on the desk.
公園こうえんに子こどもたちがいます。
There are children in the park.
駅えきの前まえに銀行ぎんこうがあります。
There is a bank in front of the station.
庭にわに猫ねこがいます。
There is a cat in the yard.
