もし

if · JLPT N4

Example sentences

もし雨あめが降ふったら、試合しあいは中止ちゅうしです。
If it rains, the game will be canceled.
もしお金かねがあったら、世界せかいを旅行りょこうしたいです。
If I had money, I would like to travel around the world.
もしわからなかったら、聞きいてください。
If you don't understand, please ask.
