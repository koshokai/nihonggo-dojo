走る (はしる)

to run · JLPT N5

Example sentences

毎朝まいあさ公園こうえんを走はしります。
I run in the park every morning.
廊下ろうかを走はしらないでください。
Please don't run in the hallway.
走はしって学校がっこうへ行いきました。
I ran to school.
