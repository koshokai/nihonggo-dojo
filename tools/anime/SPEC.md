# 动漫·日剧名台词：内容规范

每个文件 `tools/anime/<组名>.json` 是一个数组，每部作品一项：

```json
{
  "id": "onepiece",                      // 小写英文，唯一
  "kind": "anime",                       // anime 或 drama
  "title": "ONE PIECE",                  // 日文原名
  "zh": "海贼王",                         // 中文通行译名
  "year": "1999–",                       // 动画 / 电视剧首播年份
  "photo": "Kumamoto Prefectural Office / Kumamoto Castle",   // Wikimedia Commons 英文搜索词，" / " 分隔 1–3 组，找不到合适的就写 ""
  "place": "原作者尾田荣一郎的家乡熊本，县内各地立着草帽一伙的铜像。",   // 照片和作品的关系（中文，40 字内）；photo 为空时写作品一句话简介
  "lines": [
    {
      "jp": "海賊王に俺はなる！",
      "kana": "かいぞくおうに おれは なる！",
      "zh": "我要成为海贼王！",
      "who": "モンキー・D・ルフィ",
      "lv": "N4",                         // 理解这句话大概需要的 JLPT 级别
      "scene": "路飞第一次向别人宣告自己的梦想。",          // 自己写的场景简述（中文，40 字内），不要抄剧情原文
      "note": "「〜になる」表示变成、成为。正常语序是「俺は海賊王になる」，把「海賊王に」提到前面是为了强调。「俺」是男性很随意的自称。",   // 语法和语感说明（中文，60–150 字）
      "words": [["海賊王", "かいぞくおう", "海贼王"], ["俺", "おれ", "我（男性，随意）"]],   // 2–5 个生词：[写法, 读音, 中文]
      "talk": [                            // 自己编的生活小对话（2–4 句），把这句台词或其中的表达用在日常场景里（可以是玩梗）
        ["A", "来年は絶対N2に合格する！", "らいねんは ぜったい エヌにに ごうかくする！", "明年一定要考过 N2！"],
        ["B", "おお、海賊王みたいだね。", "おお、かいぞくおうみたいだね。", "哇，跟要当海贼王似的。"]
      ]
    }
  ]
}
```

## 规则（重要）

1. **只收真正广为流传的名台词**，必须是你非常确定原文一字不差的版本（日本网上反复被引用的那种）。拿不准原文措辞的，宁可不收。每句尽量短（30 字以内），不要整段抄剧本。
2. 每部作品 3–5 句。`scene`、`note`、`talk` 全部是自己写的原创内容，不要复制剧情简介或台本。
3. `kana` 用全平假名（外来语可以用片假名），词和词之间用空格隔开，方便初学者跟读；`talk` 每句也给平假名读音。
4. 不收色情、歧视或过分暴力的台词。粗话可以收，但 `note` 里要说明是粗鲁的说法、生活中别乱用。
5. `photo` 搜索词：Wikimedia Commons 上的**真实照片**，比如作品的原型地、圣地巡礼地点、作者家乡、纪念馆外观、相关的城市风景。**不要**搜角色、截图、海报、手办、铜像特写（有版权）。搜索词用文件名里大概率会出现的英文地名（例如 `Kamado Shrine`、`Kamakurakokomae Station`、`Suga Shrine Yotsuya`）。没有合适地点就写 `""`。
6. 写完用 `python3 -c "import json;json.load(open('文件'))"` 检查 JSON 能解析。
