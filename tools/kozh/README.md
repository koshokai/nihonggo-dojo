# 韩语分级词库的中文释义

`ko_graded.tsv` / `in_XX.tsv` 每行：`键<TAB>词<TAB>词性<TAB>汉字<TAB>英文<TAB>日文<TAB>等级<TAB>韩语释义`
（来自国立国语院《한국어기초사전》，CC BY-SA 2.0 KR）。

要写 `zh_XX.tsv`：每行 `键<TAB>中文释义`，行数、顺序和 in_XX.tsv 完全一致，键原样复制。

- 中文释义简洁（一般 2–12 个字，多义用「；」分隔，最多 3 个），像词典义项，给中文母语的学习者看。
- 参考韩语释义（最准确）、英文、日文和汉字来源。汉字词的中文释义通常就是对应的现代汉语词（例：교양서 敎養書 → 文化读物；修养类书籍）。
- 词尾、助词、接辞（词性是 어미、조사、접사）写成语法说明，例：`-가 家（접사）` → `……家（表示从事某行业的人）`；`-고` → `（连接语尾）……而且；……然后`。
- 动词、形容词用「……」形式（例：가다 → 去；走）。
- 不能留空，不要用 Tab 和换行。
检查：`python3 tools/kozh/check.py`

## 例句翻译

`ex_in_X.tsv` 每行：`键<TAB>韩语例句`（来自《한국어기초사전》）。要写 `ex_zh_X.tsv`：每行 `键<TAB>中文翻译`，行数、顺序一致，键原样复制。
翻译自然、准确、简洁（简体），不要漏译，不要加解释。
