# 韩语 / 英语入门数据（给中文母语者）

文件：tools/lang/ko.json、tools/lang/en.json，结构：

```json
{
  "words": [["词", "发音提示", "中文", "分类"]],
  "phrases": [["句子", "发音提示", "中文", "场景"]]
}
```

- 韩语：发音提示用**修订罗马字**（例：안녕하세요 → annyeonghaseyo）。
- 英语：发音提示用**美式 IPA**，不带斜杠（例：water → ˈwɔːtər）；句子的发音提示留空字符串 ""。
- 中文释义简洁准确（简体）。
- 单词 500 个，按分类排列，每类 20–40 个，分类用中文，从这些里选：
  问候礼貌、数字、时间日期、家人人物、身体、食物饮料、水果蔬菜、颜色、衣服、家居用品、交通出行、地点建筑、学校学习、工作职业、
  天气季节、动物、动作（动词）、形容词、购物、旅行、情感、疑问词
  （韩语的数字要同时有汉字词数字 일 이 삼 和固有词数字 하나 둘 셋，分别注明）。
  选最常用、最实用的入门词（韩语参考 TOPIK I 词汇，英语参考小学/初中核心词汇）。动词、形容词用词典形（韩语 -다 形）。
- 句子 150 句，按场景排列，每类 10–20 句，场景从这些里选：
  打招呼、自我介绍、感谢道歉、餐厅点餐、购物砍价、问路交通、酒店、机场、电话、紧急求助、聊天、职场、约会邀请、网上常用
  韩语句子以礼貌的 해요体为主，必要时加几句敬语和半语并在中文里注明（敬语）（半语）。英语用自然的日常口语。
- 全部原创，不能有重复。JSON 必须合法。
