# 韩语 / 英语商务：扩充内容规范

和日语「商务」看齐：场景会话（带照片和小测验）、场景表达、邮件模板、商务词汇。所有说明用简体中文。

## A. 场景会话 `tools/lang2/<lang>_biz3.json`

```json
{"scenes": [
  {
    "cat": "职场基础",            // 职场基础 / 电话 / 拜访接待 / 会议 / 汇报沟通 / 道歉拒绝 / 谈判销售 / 求职面试 / 应酬 / 出差
    "lv": "中级",                 // 韩语：初级 / 中级 / 高级（对应 TOPIK 1–2 / 3–4 / 5–6）；英语：四级 / 六级 / 雅思
    "title": "첫 출근 인사",       // 目标语言的标题
    "zh": "入职第一天向同事打招呼",
    "photo": "Gangnam office building / Seoul office",   // Wikimedia Commons 英文搜索词，" / " 分隔 1–3 组：真实的城市、办公楼、车站、会议室等，不要人物特写、logo、海报；没有合适的写 ""
    "note": "（中文 80–200 字）这个场景的礼仪、语气分寸和中国人常犯的错误。",
    "lines": [["팀장 (김민수)", "여러분, 오늘부터 우리 팀에 새로 온 왕리 씨입니다.", "各位，这是今天起加入我们团队的王丽。"]],   // 6–10 句对话：[说话人, 原文, 中文]
    "phr": [["오늘부터 ~팀에서 일하게 된 ~입니다", "自我介绍：说明从今天起在哪个部门工作"]],     // 4–7 个关键表达：[表达, 中文说明]
    "q": [["새 회사에서 처음 인사할 때 가장 알맞은 말은?", "처음 뵙겠습니다. 왕리라고 합니다.", "안녕? 나 왕리야.", "왕리입니다. 잘 부탁해.", "누구세요?"]]   // 3 道选择题：[题目, 正确答案, 错误1, 错误2, 错误3]（题目用目标语言或中文都可以）
  }
]}
```

写 16 个场景，覆盖上面 10 个分类（职场基础、电话、拜访接待、会议、谈判销售各 2 个，其余各 1 个）。人名、公司名都是虚构的；中国员工在当地公司工作的视角最好。

## B. 更多表达、邮件和词汇 `tools/lang2/<lang>_biz2.json`

```json
{
  "phrases": [{"scene": "催促进度", "items": [["原文", "中文", "（中文）语气说明、使用场合"]]}],   // 新增 10 个场景，每个 6–8 句；不要和已有场景重复
  "emails": [{"title": "中文标题", "zh": "一句话说明用途", "body": ["原文第 1 行", "", "..."], "bodyZh": ["对应中文", "", "..."]}],   // 新增 10 封；body 和 bodyZh 行数一致，空行对空行
  "vocab": [{"cat": "公司组织", "words": [["원문", "中文", "例句（原文）", "例句中文"]]}]   // 10 个分类，每类 20 个词 = 200 个
}
```

词汇分类：公司组织、职位称呼、日常业务、会议、销售营业、财务会计、人事劳务、贸易物流、IT办公、求职就职。英语给常用的美式商务说法；韩语给常用汉字词时可以在中文里注明汉字（例：「부서（部署）部门」）。

## 共同规则

- 语言要自然、地道，是当地职场真的会说的话，不要直译中文。
- 写完用 `python3 -c "import json;json.load(open('文件'))"` 检查能解析。不要 git add / commit。
