# 韩语 / 英语板块内容（给中文母语的学习者）

全部原创（不能抄教材、真题、网站），语言自然地道，中文用简体。每个文件写完用 `python3 tools/lang2/check.py` 检查。
「级别」：韩语用 `初级`（≈TOPIK 1–2）、`中级`（≈TOPIK 3–4）、`高级`（≈TOPIK 5–6）；英语用 `基础`（初高中）、`四级`、`六级`。

## 1. 语法 `<lang>_grammar.json`（各 90 个，三个级别各 30）

```json
[{"lv": "初级", "p": "-고 싶다", "m": "想……", "use": "接在动词词干后表示说话人的愿望；第三人称用 -고 싶어하다。",
  "eg": [["저는 한국에 가고 싶어요.", "我想去韩国。"], ["…", "…"], ["…", "…"]],
  "q": ["주말에 영화를 （ ）.", ["보고 싶어요", "봐고 싶어요", "보고 싶다고 해요", "보는 싶어요"]]}]
```
- p：语法点（英语写成 `be used to doing` / `虚拟语气 if I were…` 这种），m：中文意思，use：接续和用法（1–2 句），eg：3 个例句，q：一道选择题（正确答案写第一个，题干空白用 `（ ）`）。
- 按级别从易到难排列，覆盖该级别最核心的语法。

## 2. 阅读 `<lang>_reading.json`（各 30 篇：初级/基础 10、中级/四级 12、高级/六级 8）

```json
[{"lv": "初级", "cat": "韩国生活", "title": "편의점 도시락", "zh": "便利店便当", "photo": "Korean convenience store lunch box / Dosirak",
  "p": [[["한국 편의점에는 도시락이 많아요.", "韩国便利店里有很多便当。"], ["…", "…"]], [["第二段第一句", "中文"]]],
  "w": [["도시락", "dosirak", "便当"]], "q": [["问题（用目标语言）", "正确", "错1", "错2", "错3"]]}]
```
- 题材贴近生活、有具体细节、有趣：韩语用 `韩国生活`、`韩国美食`、`职业日常`、`节日季节`；英语用 `英美生活`、`英美美食`、`职业日常`、`节日季节`、`科技社会`。
- 2–3 段，共 6–12 句；w 6–9 个生词（韩语发音写修订罗马字，英语写美式 IPA）；q 3 题。
- photo：Wikimedia Commons 英文搜索词 2–3 组，用 ` / ` 分隔，要能搜到真实照片。事实要准确，不写价格等会变的数据。

## 3. 听力 `<lang>_listen.json`（各 40 题）

格式和日语听力完全一样（见 tools/listen/SPEC.md 的 JSON 字段：t, intro, lines, q, c, cz, a, ex），但只用这 4 种题型：
- `sokuji` 听一句话选回应（3 个选项，只朗读）：12 题
- `kadai` 对话后问「接下来做什么 / 要买什么」（4 个选项显示文字）：10 题
- `point` 对话或独白后问原因、细节、内容一致（4 个选项）：10 题
- `gaiyou` 独白（讲座、广播、新闻）后问主旨（4 个选项，只朗读）：8 题
- intro / q 用目标语言写（韩语：「남자와 여자가 이야기하고 있습니다. 남자는 이어서 무엇을 하겠습니까?」；英语：「Listen to the conversation. What will the man do next?」）。
- 三个级别平均分布，在每题里加 `"lv"` 字段。干扰项要在对话里出现过。数字用文字写（韩语用韩文，英语可写阿拉伯数字）。

## 4. 今日一句 `<lang>_daily.json`（各 366 句，不重复）

`[["句子", "发音提示", "中文", "说明"]]`：实用的日常表达、俗语、谚语、名言、流行说法（标注出处或用法），说明 1–2 句中文（什么场合用、语感、文化背景）。韩语发音写修订罗马字，英语写 ""。从易到难混合，按季节大致排列（1 月新年 … 12 月年末）。

## 5. 商务 `<lang>_biz.json`

```json
 "emails": [{"title": "中文标题", "zh": "用途", "body": ["第一行", "第二行"], "bodyZh": ["中文", "中文"]}]}
```
- phrases：8–10 个场景（自我介绍、电话、会议、邮件常用句、请求、拒绝与道歉、谈判、面试、出差、职场闲聊），每个场景 8–12 句，共约 100 句；韩语注意敬语（합쇼체 / 해요체，说明里写清楚）。
- emails：10 封常用商务邮件模板（询价、预约会议、致谢、催促、道歉、拒绝、求职……）。
