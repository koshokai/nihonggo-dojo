# 听力题数据格式（tools/listen/N?.json）

全部为原创题目，按 JLPT 听解的题型和难度编写（不得抄写或改写任何真题、教材、网站上的题目）。
音频由 VOICEVOX 按脚本合成，所以脚本就是音频的全部内容：不要写「（笑）」「（ドアの音）」这类舞台说明。

每个文件是一个 JSON 数组，每题一个对象：

```json
{
  "t": "kadai",
  "intro": "男の人と女の人が話しています。男の人はこのあと何を買いますか。",
  "lines": [["M", "日语台词", "中文翻译"], ["F", "…", "…"]],
  "q": "男の人はこのあと何を買いますか。",
  "c": ["选项1（日语）", "选项2", "选项3", "选项4"],
  "cz": ["选项1中文", "…", "…", "…"],
  "a": 2,
  "ex": "中文解说：正确答案的依据在哪一句，干扰项为什么不对（1–3 句）"
}
```

- 说话人代码：`M` 男、`F` 女、`M2` 第二个男人、`F2` 第二个女人（同性两人对话时用）。旁白（intro、q、读选项）由系统自动用播音员声音，不要写进 lines。
- 对话里称呼要和说话人性别一致（intro 写「男の人と女の人」，lines 就必须只有 M 和 F）。
- `a` 是正确选项的下标（从 0 开始）。整个文件里正确答案的位置要均匀分布，不要总是同一个。
- 干扰项必须都在对话里出现过或被提到过（例如先说要买 A，后来改成 B），要让只听懂一半的人选错——这是 JLPT 听解的核心。
- 台词要自然口语（〜んです、〜ちゃう、えっと、あ、そうか 等按级别适度使用），汉字和送假名写法规范。
  读音有歧义的词（例如人名、「今日／こんにち」「一日／ついたち」「何人／なんにん」、数字+量词）请直接写平假名，保证合成读音正确。
  数字写成汉字或假名（例如「三時」「さんぜんえん」），不要写阿拉伯数字或符号（%、～、→）。
- 词汇和语法不能超出该级别太多；越高级别，语速、信息量、干扰越难。

## 题型（t）和怎么写

| t | 名称 | 级别 | intro | lines | q | c |
|---|---|---|---|---|---|---|
| kadai | 課題理解 | 全部 | 场景 + 问题 | 对话 6–14 句 | 同一个问题 | 4 个，屏幕上显示文字 |
| point | ポイント理解 | 全部 | 场景 + 问题（常问理由「どうして」「何が一番〜」） | 对话 6–14 句 | 同一个问题 | 4 个，显示文字 |
| gaiyou | 概要理解 | N3 N2 N1 | 场景（如「ラジオで男の人が話しています。」），**不说问题** | 独白或对话 5–10 句，讲一个观点/主题 | 问主旨（「話のテーマは何ですか」「男の人は何について話していますか」「〜についてどう考えていますか」） | 4 个，**只朗读不显示** |
| hatsuwa | 発話表現 | N5 N4 N3 | 情景说明 + 「何と言いますか。」例如「レストランで店員を呼びます。何と言いますか。」（真题是看图，这里用一句话交代情景） | 空数组 [] | 空字符串 "" | 3 个短句，**只朗读** |
| sokuji | 即時応答 | 全部 | 空字符串 "" | **只有一句**，例如 [["F","あれ、まだ帰らないんですか。","咦，还不回去吗？"]] | 空字符串 "" | 3 个回应，**只朗读**；正确的是自然的回应，干扰项用相似词或误解语气 |
| tougou | 統合理解 | N2 N1 | 场景 + 「〜はどれを選びましたか」类问题 | 3 人讨论（用 M、F、M2 或 F2）比较 3–4 个方案，10–16 句，最后有人做出选择 | 同一个问题 | 4 个，显示文字（方案名） |

kadai / point / tougou 的 intro 最后一句就是问题，q 再重复一遍（考试里就是先问、听完再问一次）。

## 每个级别的题量

- N5：kadai 8、point 7、hatsuwa 5、sokuji 8（共 28）
- N4：kadai 8、point 7、hatsuwa 5、sokuji 8（共 28）
- N3：kadai 6、point 6、gaiyou 4、hatsuwa 4、sokuji 9（共 29）
- N2：kadai 6、point 6、gaiyou 5、sokuji 11、tougou 3（共 31）
- N1：kadai 6、point 7、gaiyou 6、sokuji 12、tougou 3（共 34）

场景要丰富：学校、公司、商店、车站、医院、电话、留学生活、打工、搬家、旅行、天气、图书馆、市役所、大学的研究室、新闻/广播（N2 N1）、讲座等，不要重复同一个场景。

写完用 `python3 -c "import json;d=json.load(open('tools/listen/N5.json'));print(len(d))"` 检查 JSON 合法。
